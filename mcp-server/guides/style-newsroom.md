# House style: newsroom collage

Documentary-collage explainer on aged archival paper. Newsroom-serious,
layered, tactile, slightly retro. Every scene template already implements this
look; this file tells you how to write content that suits it.

## The world

- **The stage** is a persistent archival map-paper field with a faint
  graticule, print grain and a vignette. It never cuts; blocks whip across it.
- **Palette:** Archival Tan `#C9BB9C`, Ink Black `#1A1A1A`, Halftone Gray
  `#8C8C8C`, Hot Red `#D62E1F`, Mustard `#D9A441`.
  - Red is the one accent: underlines, the highlighted bar, the line on a
    chart, the winning card, map pins. Use it for the thing the narration is
    about, and only that.
  - Mustard is secondary: labels, tags, the active caption word.
- **Type:** Anton (condensed caps) for headlines, numbers and captions;
  Source Serif 4 for body lines and quotes; Special Elite (typewriter) for
  labels and "Fig." source notes.
- **Finish:** torn-paper card edges, offset ink shadows, halftone dots, matte.
  No gloss, no 3D, no lens flares.

## Motion vocabulary

Built into the templates, listed so you can storyboard with it in mind:

- Whip-in with motion blur at the start of each block, whip-out at the end, so
  hard cuts read as one continuous camera move.
- A slow 3% push across every hold.
- Spring entrances with slight overshoot for words and cards.
- Stamp impacts with a short shake when a number or marker lands.
- Counters tick up with a strong ease-out; bars grow one after another; lines
  draw themselves.
- Karaoke captions in the lower band: white condensed caps with an ink stroke,
  the spoken word boxed in mustard.

## Writing for the templates

| Scene | Best for | Keep it to |
|---|---|---|
| `headline` | cold open, a question, a turn | ≤ 8 words, one `highlight` word |
| `stat` | the hook number | one number, a label under ~6 words |
| `bar_chart` | ranking, share | 2–6 bars, one highlighted |
| `line_chart` | change over time | 4–12 points, an annotation on the end |
| `comparison` | A vs B, before/after, cost vs revenue | short values like "$20B" |
| `list` | causes, warning signs, steps | 3 items, one line each |
| `timeline` | how we got here | 3–5 events, highlight the pivotal one |
| `quote` | a verified line from a named person | under ~25 words |
| `image` | an object, a document, a map with pins | one asset, a short caption |
| `end_card` | the kicker and the sources | one line, optional CTA |

Short on-screen text is not a preference: the caption band already shows the
narration, so a long on-screen sentence makes the viewer read the same thing
twice.
